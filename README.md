# Joalor64's Modbox
A collection of tools I made for Incredibox modding.

**Try it out:** https://joalor64.github.io/Modbox

## Current Tools
* **Polo Animator**: load a polo spritesheet, pose the head frame by frame (drag, arrow keys, head picker) and export the animation JSON. Supports HD sheets, cell gaps, audio preview and undo.
* **App.js Generator**: fill in your mod's info, polos, bonuses and colours, then export a legacy `app.js`, a Rem's Modding Build `apps.js` or an official mod `app.json`. Can open all three.
* **Looptime + Totalframe Finder**: BPM ⇄ looptime, plus totalframe and frames per loop.
* **Spritesheet Generator**: combine full/body/silhouette and head images into HD + LD polo spritesheets and a starter JSON.
* **Title SVG Generator**: make the light and dark home-screen title SVGs and the CSS for them.
